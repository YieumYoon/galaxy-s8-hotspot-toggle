# Security Policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability in this project. Use GitHub's
private vulnerability reporting feature from the repository's **Security** tab.

Include the affected commit or release, a minimal reproduction, impact, and any
suggested mitigation. Remove device identifiers, subscriber information, Wi-Fi
details, access tokens, signing material, and unrelated logs before submitting.

## Scope

Reports about the app, build scripts, CI configuration, or documentation are in
scope. Carrier billing disputes, account entitlement questions, and vulnerabilities
in Samsung or Android firmware should be reported to the relevant vendor.

The repository intentionally documents a legacy firmware behavior. A report that
only restates that documented behavior is not a new vulnerability in this project.
